# Experiment tracking

We use **Weights & Biases**. See [ADR 0002](decisions/0002-experiment-tracking.md) for the comparison with MLflow.

## Setup

```bash
# .env
WANDB_API_KEY=...        # https://wandb.ai/authorize
WANDB_ENTITY=dermiai     # shared team
```

Set `WANDB_MODE=offline` to log locally without a network connection (sync later with `wandb sync`).
Set `tracking.backend: none` in a config for smoke runs.

## Projects

| W&B project | Used by |
|---|---|
| `dermiai-llm` | all LLM stages, persona data generation, eval |
| `dermiai-vision` | CNN training / eval |

## Naming conventions

**Run name:** `{area}-{step}-{experiment}-{yyyymmdd}-{gitsha7}`
(generated by `dermiai_llm.tracking.make_run_name`)

```
llm-sft-sft-lr2e4-r32-20261029-a1b2c3d
vision-train-effnetb3-aug2-20261102-9f8e7d6
```

- `experiment` = `experiment.name` in the config. Use lowercase kebab-case with at most 48 characters, and keep it unique.
- **Group** = stage or sweep (`cpt`, `sft`, `dpo`, `eval`, `sft-sweep-lr`).
- **Tags** = free-form (`baseline`, `ablation`, `final`).
- **Artifacts:** `{experiment}:v{n}` for adapters and datasets. Downstream configs reference them in `model.init_adapter`.

## Every run must log

1. The full resolved config (`wandb.config = cfg.model_dump()`)
2. The git sha and whether the tree was dirty
3. The DVC data version (`dvc.lock` hash, or the `.dvc` md5 of the dataset)
4. Its output as an artifact if downstream work uses it

Runs that are reported (thesis, demo) get the `final` tag and a link in the model card.
